# Reproduction Instructions

All commands run from the repository root. No network access is required.

## 1. Verify the frozen inputs

```powershell
python scripts/verify_checksums.py
```

This checks every file listed in `reproducibility/checksums.sha256`.

## 2. Run the test suite

```powershell
python -m pytest tests -q
```

The suite checks:

- frame row count, strata, year counts, and SHA-256;
- pilot coding schema, flow, score distribution, eligibility, and reliability caveats;
- Wilson intervals and exact-binomial diagnostics;
- table and figure source data against the pilot table;
- manuscript presence of key numbers and absence of placeholders;
- human-coding templates against the pilot metadata;
- agreement-script arithmetic, duplicate keys, missing keys, and degenerate κ;
- checksum integrity.

To validate the committed table or a new coding CSV without running the suite:

```powershell
python scripts/validate_coding.py pilot/pilot_coding_table.csv
```

The validator checks the [documented coding fields](data_dictionary.md#3-pilotpilot_coding_tablecsv),
including eligibility, score, engagement and duplicate `paper_key` plus `critique`
pairs. It reports each violation with the CSV row number (header = 1) and
column, then exits with code 1. It does not modify the input file.

## 3. Recompute the pilot analysis

```powershell
python scripts/analyze_pilot.py
```

Reads `pilot/pilot_coding_table.csv`, writes:

- `analysis/pilot_results.json`
- `analysis/pilot_results.md`
- `analysis/pilot_rows_normalized.csv`

Expected key values:

| Quantity | Value |
|---|---|
| Primary-pair full adoption | 1/6 = 16.7% |
| Primary-pair Wilson 95% CI | 3.0–56.4% |
| All-pair full adoption | 1/8 = 12.5% |
| All-pair Wilson 95% CI | 2.2–47.1% |
| Acknowledged or better, primary | 4/6 = 66.7% |
| Independent remediation, primary | 3/6 = 50.0% |
| H1 exact-binomial p (primary) | 0.534 |
| H3 exact-binomial p (primary) | 0.109 |

The JSON generation timestamp changes on each run; the counts do not.

## 4. Check the human double-coding package (prepared, not executed)

The pilot had no human second coder. The package in
`reproducibility/human_coding/` is ready for one, but no human has completed the
sheets. The pilot's κ values remain **LLM–LLM**.

The package contains:

- `README.md`: instructions, blinding rules, and the field guide;
- `coder_A.csv` and `coder_B.csv`: blank sheets with the 12 pilot rows' metadata
  filled and every coding field empty;
- `paper_sources.csv`: open-access and publisher links for all 12 papers, with no
  coding information;
- `recruitment_note.md`: a ready-to-send invitation and the independence questions
  to ask before coding.

After both completed sheets exist, run the status wrapper:

```powershell
python scripts/human_coding_status.py --run
```

It checks that both sheets are present and share exactly the same keys, prints a
short readiness summary, then runs the agreement calculation. To check readiness
without computing statistics:

```powershell
python scripts/human_coding_status.py
```

```powershell
python scripts/agreement.py `
  --coder-a reproducibility/human_coding/coder_A_completed.csv `
  --coder-b reproducibility/human_coding/coder_B_completed.csv
```

The script keys on `paper_key` + `critique`. It exits with code 2 if a key is
missing from one sheet, appears twice, or a score is out of range. It does not
silently intersect the two sheets.

It writes:

- `analysis/human_coding/agreement_report.json`
- `analysis/human_coding/agreement_report.md`
- `analysis/human_coding/agreement_disagreements.csv`

The report includes eligibility κ, ordinal unweighted/linear/quadratic κ,
bootstrap percentile intervals, confusion matrices, and the disagreement list.
A κ of `null` means expected agreement was 1.0 and κ is undefined; the script does
not substitute 1.00. That is deliberate. With 12 rows, treat the values as a
calibration signal, not a stable reliability estimate.

The blank templates are committed. Completed sheets and generated agreement
outputs are gitignored working data. They are not covered by
`reproducibility/checksums.sha256`.

To check that the templates still match the frozen pilot metadata and that the
script's arithmetic still passes its fixtures:

```powershell
python -m pytest tests/test_agreement.py -q
```

## 5. Regenerate tables and figures

```powershell
python scripts/make_manuscript_tables.py
python scripts/make_figures.py
```

Both scripts read the frozen frame, pilot table, and/or analysis JSON and rewrite
the Markdown/CSV tables and SVG figures. The committed outputs were generated by
these scripts.

## 6. Build the frame from source metadata (optional, network required)

```powershell
python scripts/fetch_citations.py
python scripts/build_frame.py
```

This step is not needed to verify the pilot. It requires Semantic Scholar API
access and may produce a different snapshot because the API changes over time. A
new snapshot is **not** the frozen frame and must not replace it without a
documented protocol amendment.

## 7. Draw the feasibility cohort (optional)

```powershell
python scripts/sample_frame.py --design feasibility
```

The committed cohort has seed `20261113` and 335 records. Re-running with the same
seed and frozen frame should reproduce the same draw. The cohort was not coded and
is not used in any result.

## Expected repository state

After steps 1–5, `git status` should show only the regenerated analysis JSON's
timestamp (if step 3 was run) and no substantive changes. The tests do not modify
frozen inputs. Running `scripts/agreement.py` on completed sheets writes only
ignored files under `analysis/human_coding/`; it does not touch the frozen pilot
table.

## Troubleshooting

- **`pytest` not found:** `python -m pip install pytest`.
- **Checksum failure:** do not edit the frozen file to make the test pass. Inspect
  the diff, restore the committed version, or document an intentional amendment.
- **Unicode display issues in PowerShell:** files are UTF-8. Read them with an
  editor or `python -c "print(open(..., encoding='utf-8').read())"`.
- **Matplotlib missing:** not needed. Figures are generated as SVG by
  `scripts/make_figures.py`; no plotting library is required.
- **Agreement script says a key is missing or duplicated:** fix the completed
  sheet. Do not edit the key in one file to make it match, and do not add a
  fallback inner join. The strict failure is the point.
- **Agreement script says κ is undefined:** expected agreement was 1.0. Report
  the raw agreement and say κ is undefined; do not change the value to 1.00.
